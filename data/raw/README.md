# Raw data (not committed)

Download the **CEAS_08.csv** file from the public phishing-email corpus collection
(CEAS 2008 Challenge subset; columns: sender, receiver, date, subject, body, label, urls)
and place it here as `data/raw/CEAS_08.csv`.

Please read the dataset's licence/terms before redistributing it.
Only `data/processed/` (derived sequences) is committed.
